# นโยบายความปลอดภัยสารสนเทศและการใช้งานที่เหมาะสม

## 1. บัญชีผู้ใช้และรหัสผ่าน
- รหัสผ่านยาวอย่างน้อย **14 ตัวอักษร** ห้ามใช้ซ้ำกับ 5 รหัสล่าสุด เปลี่ยนทุก 180 วัน
- ต้องเปิด **MFA** (Microsoft Authenticator) ทุกบัญชี
- ห้ามแชร์บัญชีหรือรหัสผ่านให้ผู้อื่น รวมถึงเพื่อนร่วมทีมและเจ้าหน้าที่ IT — เจ้าหน้าที่ IT จะไม่ขอรหัสผ่านของคุณ

## 2. การจัดชั้นข้อมูล (Data classification)
| ชั้น | ตัวอย่าง | ข้อกำหนด |
|---|---|---|
| Public | ข่าวประชาสัมพันธ์ | เผยแพร่ได้ |
| Internal | นโยบายบริษัท คู่มือพนักงาน | ใช้ภายในบริษัท |
| Confidential | ข้อมูลลูกค้า สัญญา source code | เฉพาะผู้มีหน้าที่เกี่ยวข้อง ห้ามส่งออกนอกระบบบริษัท |
| Restricted | เงินเดือน ข้อมูลสุขภาพ เลขบัตรประชาชน | เฉพาะผู้ได้รับอนุญาตเป็นรายบุคคล ต้องเข้ารหัสและบันทึกการเข้าถึง |

## 3. ข้อมูลส่วนบุคคล (PDPA)
- ห้ามพิมพ์หรือแนบ **เลขบัตรประชาชน** เลขบัญชีธนาคาร หรือข้อมูลสุขภาพ ลงในแชท อีเมลทั่วไป หรือ ticket
- หาก HR ต้องการเอกสารดังกล่าว ให้ส่งผ่านช่องทางอัปโหลดเอกสารใน NawaHR เท่านั้น
- ระบบ AI Copilot ของบริษัทจะปิดบัง (mask) ข้อมูลประเภทนี้อัตโนมัติก่อนประมวลผลและก่อนบันทึก log

## 4. การใช้ AI
- ใช้ **Nawa Copilot** (ระบบ AI ภายในบริษัท) สำหรับคำถามที่เกี่ยวกับข้อมูลภายใน
- ห้ามนำข้อมูลชั้น Confidential หรือ Restricted ไปใส่ในบริการ AI สาธารณะที่บริษัทไม่ได้อนุมัติ
- คำตอบจาก AI อาจผิดพลาดได้ ให้ตรวจสอบกับเอกสารอ้างอิงที่ระบบแนบมาทุกครั้งก่อนนำไปใช้ตัดสินใจ

## 5. การขอสิทธิ์เข้าถึงระบบ
- ขอสิทธิ์ (shared drive, database, GitHub, ระบบภายใน) ผ่านแบบฟอร์ม **AR-01** ใน NawaFlow โดยหัวหน้างานต้องอนุมัติก่อน แล้ว IT Infrastructure & Security จะดำเนินการ
- ให้สิทธิ์ตามหลัก **least privilege** — สิทธิ์เข้าฐานข้อมูล production สำหรับงานวิเคราะห์ให้เป็นแบบ read-only ผ่าน role `analyst_ro` เท่านั้น
- สิทธิ์ทั้งหมดจะถูกทบทวนทุกไตรมาส และถูกถอนอัตโนมัติเมื่อย้ายทีมหรือพ้นสภาพพนักงาน

## 6. การแจ้งเหตุด้านความปลอดภัย
- พบอีเมลน่าสงสัย ให้กดปุ่ม **Report phishing** ใน Outlook
- ถ้าเผลอคลิกลิงก์หรือกรอกรหัสผ่านในเว็บน่าสงสัย ให้โทร **1111** ทันที (ถือเป็น P2) และเปลี่ยนรหัสผ่าน
- อุปกรณ์สูญหาย แจ้งภายใน 24 ชั่วโมง IT จะสั่งล้างข้อมูลจากระยะไกล

## 7. อุปกรณ์
- notebook ของบริษัทเข้ารหัสดิสก์ด้วย BitLocker และบังคับอัปเดตความปลอดภัยผ่าน Intune
- อัปเดต BIOS/firmware จะถูกส่งโดย IT เท่านั้น ระหว่างอัปเดตห้ามปิดฝาเครื่องหรือถอดสายชาร์จ
- ห้ามติดตั้งโปรแกรมที่ไม่ได้อยู่ใน Company Portal หากต้องการให้เปิด ticket P4 หมวด Software request
